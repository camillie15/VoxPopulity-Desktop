# 📦 Configuración del Proyecto

Este proyecto utiliza las siguientes dependencias y requiere una base de datos MySQL para funcionar correctamente.

---

## 📚 Dependencias

- **mysql-connector-j** `v8.4.0`
- **org.eclipse.persistence.jpa** `v4.0.3`

---

## 🗄️ Base de Datos

**Nombre:** `voxPopulidb`  
**Usuario:** `admin`  
**Contraseña:** `1234`

---

## 🚀 Pasos Iniciales

1. Crear una base de datos (schema) llamada **`voxPopulidb`**.
2. Crear un usuario con permisos de administrador:
   - **Usuario:** `admin`
   - **Contraseña:** `1234`
3. Ejecutar el archivo **`ProjectValidation.java`**.
4. El sistema generará automáticamente las tablas necesarias con todos sus campos.
